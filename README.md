# DLT-AI-CORE VIP

大乐透智能分析核心系统


## 功能

- 历史数据解析
- 特征工程
- 统计模型
- 贝叶斯模型
- 马尔可夫模型
- 数字矩阵模型
- 结构分析模型
- 集成模型
- Monte Carlo模拟
- 历史回测
- 开奖反馈学习


## 数据格式

data/dlt_history.txt


格式:

07001 2007-05-30 22 24 29 31 35 04 11


说明:

期号 日期
前区5个
后区2个



## 本地运行


安装:

npm install


启动:

npm start



## Render部署


Build Command:

npm install


Start Command:

npm start
