# dlt-ai-core v21.5 mobile final


## 项目名称

dlt-ai-core v21.5

大乐透 + 排列五智能分析系统



## 项目目标

基于真实历史开奖数据：

- 大乐透
- 排列五

进行数据分析、概率评分、组合筛选和历史反馈学习。



## 核心原则

本系统不是随机选号程序。

预测流程：

历史数据

↓

数据解析

↓

特征计算

↓

概率模型

↓

组合筛选

↓

模型融合

↓

输出候选结果

↓

开奖反馈学习



## 支持模型


### bayesian

贝叶斯概率评分

作用：

- 历史频率
- 概率权重


### markov

马尔可夫转移分析

作用：

- 数字变化关系
- 趋势参考


### monte carlo

蒙特卡罗模拟

作用：

- 大量组合测试
- 候选筛选


### genetic

遗传优化

作用：

- 组合评分优化
- 优胜筛选


### fusion

多模型融合

作用：

- 综合不同模型结果
